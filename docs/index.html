不塞广告、不绑账号、不偷偷联网。只做一件事：把文件从这台电脑送到那台。

一个 exe，双击就跑。不写注册表（除了右键菜单）、不留后台服务、删了就干净。

嵌套目录、空目录、中文名都按原样建出来，不会把一堆文件摊平。

关掉窗口也在收

How it works

三步就传完了

不用加好友、不用输 IP、不用建共享文件夹。

1

两边都打开

连同一个 Wi-Fi 或交换机，各自双击 LanBeam.exe。首次运行防火墙提示选「允许」。

2

选中对方

左边列表约两秒自动出现对方设备，点中它，选「发送文件…」或「发送文件夹…」。

3

对方点是

对方弹窗点「是」，内容进他的「下载\LanBeam」。想免确认就打开「自动接收」。

FAQ

常被问到的

只能收、发不出去？

对方电脑的 Windows 防火墙拦了入站。在对方电脑上：关掉 LanBeam → 右键「放行防火墙（管理员运行）.bat」以管理员运行 → 重开。包里带了这个脚本。

看不到对方的设备？

访客 Wi-Fi 常开 AP 隔离，同一网络也互相看不见。换成主网络，或点「手动添加」，填对方的 IP:端口 和界面上的令牌。

文件会经过你们服务器吗？

不会。LanBeam 没有服务器：UDP 广播发现 + 局域网内 HTTP 直传，数据不出局域网。也正因为这样，传输是明文的，敏感文件请先加密压缩再传。

支持手机、平板吗？

支持。安卓端 1.0.1 已经发布，可以直接装 APK；鸿蒙端也做好了，正在准备上架。三端共用同一套协议，同一 Wi-Fi 下互相能发现、能收发。

传大文件会不会卡内存？

不会。1 MB 分块流式发送，内存占用恒定；实测回环 400 MB/s 以上，千兆网络能跑满。

有什么已知限制？

明文传输、一次只能发一个文件夹（多个文件可以多选）、不支持 0 字节的空文件、收件目录默认固定在「下载\LanBeam」（可在设置里改）。
